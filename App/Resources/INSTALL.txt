Gallery — install

1. Double-click the zip to unpack it.
2. Drag "Gallery.app" into /Applications (or any folder where you keep apps).
3. First launch: right-click Gallery.app and choose Open, then Open again.
   Gallery is signed with a free local development certificate, not notarized by
   Apple, so macOS asks for confirmation once. That is expected and is the only
   extra step.
4. If macOS instead says the app is "damaged" (rare; some unzip tools re-pack the
   bundle), open Terminal and run:
       xattr -dr com.apple.quarantine /Applications/Gallery.app
   Then open it normally.
5. Gallery reads your folders in place and uploads nothing. Add a folder with ⌘O.

Finder
------
- Right-click a folder and choose Open With > Gallery. Gallery is an alternate
  handler, so it never takes over as the default for folders.
- Or right-click a folder and choose Services > Open Folder in Gallery. You can
  give that a keyboard shortcut in System Settings > Keyboard > Keyboard Shortcuts
  > Services.
- For a top-level Finder item, make a Quick Action in Shortcuts: New Shortcut >
  Receive Folders from Finder > Run Shell Script with
      open -b app.gallery "$@"
  then "Use as Quick Action". It appears in Finder's right-click menu under
  Quick Actions.

Updating
--------
Quit Gallery, replace the app with the new version, then re-add your folders
once. macOS ties the folder permission to the app's signature, so every new
build asks for it again.
